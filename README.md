# 翻頁島 PopIsle｜立體書學習平台 DEMO

## 怎麼開
直接用 Chrome 或 Edge 開啟 `index.html`（雙擊即可，不需要安裝任何東西）。
連上網路時字體會比較好看；沒有網路也能跑。

## DEMO 流程（建議的展示順序，約 5 分鐘）
1. 首頁按「我是老師：上傳教材」→ 選科目 → 按「生成立體書」，看五個解析步驟。
2. 按「前往學習海圖」，島嶼會從海面長出來。海圖是 3D 的：點島嶼，紙船會開過去；也可以用方向鍵或 WASD 自己開船。靠岸後按「進入立體書」。
3. 點島嶼進入立體書：① 故事預告（有配音、配樂）→ ② 猜一猜 → ③ 讀課文、點金色字詞、答提問 → ④ 揭曉 → ⑤ 測驗 → 回到海圖（島上會插旗）。
4. 點「數學島」「英文島」看規劃中的呈現方式。
右上角「重置」可以清掉進度重新展示。

## 老師上傳自己的教材 → 自動生成立體故事書
在「老師上傳」貼上課文或上傳檔案（.txt、.docx、課本頁面的照片），填課名，按「生成立體書」。
- 線上版（claude.ai 的頁面）：AI 會整理課文、分成 3–5 頁，替每一頁配場景（背景＋紙雕物件）、寫旁白、出一題理解題，再出測驗、開放題和重點整理。老師確認（可改課名、拿掉某一頁）後發布，海圖上長出新島。旁白用 Claude 語音朗讀。
- 離線版（直接開 index.html）：沒有 AI，改用規則：原文分頁、找重點詞、依關鍵字配場景、課文填空出題；旁白用電腦內建的中文語音。想指定重點詞，用【】標起來。照片教材離線版不能讀。
- 學生端：每讀完一頁、答對一題，才能翻到下一頁；最後是揭曉、重點整理和測驗。
- 示範版最多放 3 座自編島。

## 老師後台
上方「老師後台」可以看每一課的完成人數、各題答錯比例、最多人點開的字詞和教學建議。全班數字是模擬數據；每張卡片最下面是這台裝置的真實紀錄。

## 檔案
- `js/lessons.js`：三課的全部內容（對話、課文、字詞解釋、提問、測驗、場景圖層）。要改內容或加新課，只改這個檔。
- `js/art.js`：紙雕場景的繪圖程式。之後可以用 AI 生成的 PNG 取代（立體書頁面的「素材」分頁可以直接上傳試看）。
- `js/custom.js`：把老師上傳的教材變成課程（AI 解析與離線規則兩種）。
- `js/map3d.js`：3D 學習海圖（島嶼造型、紙船、靠岸選島）。
- `js/app.js`：通用引擎（立體書、翻頁、鏡頭、配音播放、海圖、上傳流程）。
- `audio/<課>/b0.mp3…`：預告每一句的配音；`hook.mp3` 是懸念提問；`read.mp3` 是課文朗讀。

## 換配音
目前是 AI 語音（Kokoro v1.1，開源、可商用）。想換成真人或其他 AI 配音時，
用同樣的檔名覆蓋 `audio/` 裡的 mp3 即可，動畫會自動依新音檔的長度對時。
每一句的台詞、檔名和情緒指示都列在 `配音台詞表.md`。

## 示範版的限制
- 三課範例的解析結果是預先製作的。自訂教材的場景只能從三組現成場景裡選。
- 每課只做了一頁立體書。
- 開放題沒有 AI 評分；學習數據只存在這台電腦的瀏覽器裡。

## 只給主題，AI 查課綱自編（新）

老師上傳頁有兩種方式：「只給主題，AI 查課綱自編」和「上傳現成教材」。

只給主題的流程（例：國一下・自然・人體的器官認識）：

1. **查課綱**：`js/curriculum.js` 是內建的課綱索引（108 課綱自然領域國中階段的學習內容，加上康軒、南一、翰林的排課學期）。目前收錄七年級自然（生物）。查詢結果會告訴老師這個主題排在哪個學期。
2. **AI 編寫**：把查到的範圍交給 AI，由它用自己的話寫課文、分頁、出題（`Custom.fromTopic`）。不照抄課本。
3. **AI 畫插圖**：每一頁請 AI 畫一張有標示的剪紙風 SVG 教學插圖（`Custom.drawArt`），清除不安全的內容後，變成立體書裡立起來的紙雕，也顯示在課文上方，可以點開放大。
4. **老師確認**：看課綱對照、每一頁的插圖、課文和提問，再發布。

離線版沒有 AI，只能示範內建範例〈人體的器官〉（`js/demo_organs.js`，格式和 AI 生成的結果相同）。

正式產品要做的事：把課綱索引換成伺服器上的即時查詢（課綱資料庫＋網路搜尋），並擴充到各年級各科。

## 書本版面：左頁課文＋提問，右頁立體場景（新）

- 預告和猜一猜時，立體書佔滿整個畫面。進入閱讀後，左邊翻出一張紙頁（`#leafPage`）：上面是課文，下面是提問；右邊是立起來的立體場景。讀、看、答、翻頁都在同一個畫面，不用捲動。
- 提問、範例課的提問和最後的測驗都用同一個元件（`BQ`，在 `js/app.js`），固定在課文下方。測驗時課文會收起來，整頁只剩題目。
- **找一找（點圖作答）**：有標示的插圖，名稱會暫時變成 A、B、C… 的字母標記（`pointOf`，在 `js/custom.js`）。學生直接點立體書上的標記（或按紙頁上的字母）找出指定的構造；答錯會告訴他點到的是什麼。答對後名稱恢復，再接這一頁的理解題。
- 手機版面：立體書固定在上半部，紙頁在下面捲動。
